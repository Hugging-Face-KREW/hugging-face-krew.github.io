이 글은 Hugging Face 블로그의 Multimodal open d1 decision models for the edge를 한국어로 번역한 글입니다.

엣지를 위한 멀티모달 오픈 d1 의사결정 모델

오늘 d1 decision model family에서 두 가지 오픈 의사결정 모델인 d1-3B과 d1-omni-600M(실험적 버전)를 공개합니다.

  • Decision Index 0.2.1에서 10B 미만 모델 중 최고의 의사결정 모델: d1-3B는 48.57점을 기록해 모든 4B 및 9B 모델과 Decider 35B-A3B(47.11)를 앞섰습니다.

  • 멀티모달: d1-3B는 텍스트와 이미지를 지원하며, d1-omni-600M은 텍스트와 이미지 또는 텍스트와 오디오를 지원합니다.

  • 빠른 속도: d1-3B는 NVIDIA Jetson AGX Thor에서 16 ms, Jetson AGX Orin에서 26 ms, Jetson Orin Nano에서 50ms 만에 질문에 답합니다.

엣지를 위한 의사결정 모델을 구축한 방법

이러한 오픈 d1 의사결정 모델은 Liquid Foundation Models(LFMs)을 기반으로 구축되었습니다. 생성 모델과 달리 의사결정 모델은 토큰을 생성하지 않고 단일 forward pass로 답변합니다.

d1-3B와 d1-omni-600M은 서로 매우 다른 두 백본으로 학습되었습니다.

  • d1-3B는 최신 VLM인 LFM2.5-VL-3B을 기반으로 학습되었으며, 이 모델은 decoder-only 구조입니다. 입력으로 텍스트와 이미지를 받습니다.

  • d1-omni-600M은 bidirectional encoder인 LFM2.5-Encoder-350M을 기반으로 학습되었습니다. 세 가지 모달리티를 모두 처리할 수 있도록 vision 및 audio encoder를 추가했습니다. 입력으로 텍스트와 이미지 또는 텍스트와 오디오를 받습니다. 이 모델은 현재 초기 연구 릴리스 단계이며 추가 개발이 진행 중입니다.

벤치마크 결과

reading comprehension, toxicity detection, intent classification, medical QA, cross-lingual understanding을 아우르는 7개의 공개 데이터셋에서 d1-3B와 d1-omni-600M을 벤치마크했습니다. d1-3B는 평균 82.9점을 기록해 표에서 가장 높았으며 Decider 4B를 앞섰습니다. d1-omni-600M은 78.4점을 기록해 Decider 2B(77.1)를 넘어섰고, 파라미터 수는 그 4분의 1에 불과합니다.

벤치마크 d1-omni-600M d1-3B Decider 2B Decider 4B
SQuAD 2.0 74.0 83.3 67.7 76.0
Civil Comments 95.8 93.3 93.6 92.8
MASSIVE intent 86.1 86.9 81.1 88.3
PubMedQA 61.3 68.3 65.7 63.3
BoolQ 77.7 86.3 87.3 89.0
XNLI 74.7 85.6 85.0 88.6
PAWS-X 79.5 76.4 59.5 69.8
평균 78.4 82.9 77.1 81.1

d1-3B가 표준 vision 벤치마크에서 LFM2.5-VL-3B 백본의 vision 기능을 유지하고, d1-omni-600M이 세 가지 모달리티를 처리한다는 것을 검증했습니다. Decision Index v0.3에는 비공개 vision 분할만 포함되어 있고 audio decision 벤치마크는 현재 미해결 과제이므로, vision 또는 audio 벤치마크 결과는 보고하지 않습니다.

속도

NVIDIA와 협력하여 NVIDIA GeForce RTX 4090, NVIDIA Jetson AGX Thor, Jetson AGX Orin 64 GB 및 Jetson Orin Nano에서 NVIDIA 스택을 사용해 d1-3B를 평가했습니다. d1-omni-600M은 초기 연구 릴리스이므로 이번 릴리스에서는 속도 수치를 보고하지 않습니다.

엣지 추론. d1-3B는 측정한 모든 기기에서 단일 질문에 50 ms 미만으로 답합니다. 질문 3개를 처리하는 데 걸리는 시간은 질문 1개를 처리하는 시간의 1.3배에 불과하며, AGX Thor에서는 16 ms에서 20 ms로 증가합니다.

  질문 1개 질문 3개 3.4K-token 상태 384px 이미지 64개 상태, 패킹
Apple M5 Pro 30 ms 41 ms 640 ms 62 ms 78 / s
Jetson AGX Thor 16 ms 20 ms 220 ms 35 ms 262 / s

GPU 추론. GPU에서 d1-3B는 두 플랫폼 모두에서 질문에 10 ms 미만으로 답하고 384px 이미지를 18 ms 미만으로 처리합니다.

오픈 d1 의사결정 모델 사용 방법

멀티모달 입력을 포함해 빠르고 구조화된 의사결정이 필요할 때 d1 의사결정 모델을 사용하세요. d1-3B는 해당 크기에서 가장 높은 의사결정 품질을 제공하며, d1-omni-600M은 모델 크기가 중요한 환경에 적합합니다.

종속 항목을 설치합니다(transformers>=5.14 필요):

pip install "transformers>=5.14" torch torchvision pillow

이 모델은 자체 코드를 포함하므로 trust_remote_code=True을 사용해 로드하세요.

import io
import urllib.request

import torch
from PIL import Image
from transformers import AutoModel

device = "cuda" if torch.cuda.is_available() else "mps" if torch.backends.mps.is_available() else "cpu"
model = AutoModel.from_pretrained("LiquidAI/d1-3B", trust_remote_code=True,
                                  dtype=torch.float32 if device == "cpu" else torch.bfloat16).to(device)

# Several named questions over one text state, answered in one pass
questions = {
    "refund": {"type": "noul", "instructions": "Is the customer asking for a refund?"},
    "team": {"type": "choice", "instructions": "Which team should handle this?",
             "criteria": {"billing": "Charges, refunds, invoices", "technical": "App or site faults",
                          "fraud": "Suspected unauthorised use"}},
    "urgency": {"type": "score", "instructions": "How urgent is this?",
                "criteria": ["Can wait", "Today", "Blocking the customer now"]},
}
print(model.system_one("I was charged twice this month, please refund one of them.", questions))

# An image as the whole state
url = "http://images.cocodataset.org/val2017/000000039769.jpg"  # two cats on a sofa
photo = Image.open(io.BytesIO(urllib.request.urlopen(url).read()))
print(model.system_one(None, {"cats": {"type": "choice", "instructions": "How many cats are there?",
                                       "criteria": {"one": "One", "two": "Two", "more": "Three or more"}}},
                       images=[photo]))

# Many requests, packed together with no padding
tickets = ["Where is my parcel? It was due Monday.", "The app crashes when I open settings."]
print(model.system_one_batch([(t, {"team": questions["team"]}) for t in tickets]))

간결하게 설명하기 위해 d1-3B 예제만 포함합니다. 실행 방법은 d1-omni-600M model card을 참조하세요.

오픈 d1 의사결정 모델 시작하기

두 의사결정 모델 모두 오픈 웨이트이며 현재 Hugging Face에서 사용할 수 있습니다.

  • 다운로드: Hugging Face에서 d1-3B 및 d1-omni-600M을 다운로드하세요.

  • 사용해 보기: Hugging Face Space의 System One Arcade에서 데모를 실행해 보세요.
