AWS Trainium에서 모델이 실행되나요? 확인해 보세요.

previous post에서 AWS Trainium용 네이티브 PyTorch 백엔드인 TorchNeuron(torch-neuronx 패키지)을 소개했습니다. 이를 사용하면 Transformers가 다른 모든 디바이스에서와 마찬가지로 Trainium에서 자체 모델링 코드를 실행하므로, Hugging Face Hub의 모든 Transformers 모델이 실행될 수 있습니다. 실제로 실행되는 모델은 무엇일까요?

torch-neuronx model support Space는 Hugging Face Hub에서 가장 인기 있는 모델을 대상으로 이 질문에 답합니다. 모델이 수정 없이 Trainium에서 실행되는지 알려 주고, 직접 실행할 수 있는 스크립트도 제공합니다.

모델 조회

Space는 Selected 보기로 열립니다. 이는 Hugging Face Hub에서 다운로드 수와 트렌딩 점수를 기준으로 선정한 상위 모델 중에서 직접 고른 모델 목록입니다. 각 행에는 결과, 모델이 샤딩된 Trainium 코어 수, 실행 시간(wall time, 컴파일 포함), 최대 디바이스 메모리가 표시됩니다.

특정 모델을 조회하려면 Trending 또는 Downloads 보기로 전환한 다음 모델 이름의 일부를 입력하세요. 이 보기에서는 모델의 테스트 여부와 관계없이 작업별로 Hugging Face Hub 자체 순위를 따릅니다. 모델을 의도적으로 제외한 경우 Space에서 그 이유를 알려 줍니다(대부분은 우선순위가 높지 않았기 때문이며, 때로는 실제로 호환되지 않기 때문입니다). 확인할 Neuron 컴파일러(neuronx-cc) 및 Transformers 버전도 선택할 수 있습니다.

[!NOTE] 이 글을 작성하는 시점에는 Transformers 모델만 테스트되며, 선택 범위도 text-generation 및 image-text-to-text 모델로 제한됩니다. 앞으로 diffusers, sentence transformers 및 기타 transformers 작업으로 범위를 확장할 계획입니다.

직접 실행하기

모델을 선택하면 실행 방법을 확인할 수 있습니다. Space에는 모델을 테스트한 Neuron 스택, 그 위에 설치해야 하는 패키지, 그리고 실행된 run.py 스크립트가 나열됩니다. 이 스크립트는 TorchNeuron announcement의 레시피를 따릅니다. 필요할 경우 모델을 샤딩하여 from_pretrained로 로드한 다음, 정적 캐시와 torch.compile(backend="neuron")를 사용해 생성합니다.

예를 들어 해당 스택이 설치된 Trainium2(trn2) 인스턴스의 AWS Neuron Deep Learning Container에서 패키지를 설치한 다음 다음 명령을 실행하세요.

python3 run.py

torchrun는 필요하지 않습니다. 모델이 샤딩된 경우 스크립트가 자체적으로 torch.distributed 랭크를 실행합니다.

처음 실행할 때는 모델의 그래프를 컴파일하는 작업부터 시작합니다. 이 단계를 건너뛰려면 테스트 중 동일한 컴파일러가 빌드한 그래프를 공개 NEFF cache 버킷에서 복사하세요. Space에서 올바른 컴파일러 버전이 포함된 명령을 제공합니다.

hf buckets sync hf://buckets/aws-neuron/torch-neuronx-neff-cache/neuronxcc-<version> /tmp/neff_cache

“실행된다”는 의미

각 테스트에서는 trn2 인스턴스에서 모델을 로드하고, 가중치를 저장할 수 있는 가장 적은 수의 Trainium 코어에 샤딩합니다. 대부분의 모델은 텐서 병렬 처리를 사용해 샤딩됩니다. 텐서 병렬 계획이 없는 mixture-of-experts 모델은 전문가 병렬 처리만 사용합니다. 그런 다음 테스트에서 32개의 토큰을 생성하고 이를 확인합니다. 단일 코어에서는 토큰을 동일한 체크포인트를 CPU에서 실행했을 때의 토큰과 비교합니다. 모델이 샤딩된 경우에는 소형 judge 모델이 텍스트가 유창한 영어인지 확인합니다.

이 글을 작성하는 시점에는 4개의 Trainium2 디바이스에 들어가는 모델만 테스트되며, 이는 최대 16개의 코어를 의미합니다. PASS는 처리량이나 더 긴 생성에 대해서는 아무것도 말해 주지 않습니다.

결과는 데이터셋입니다

Space에 표시되는 모든 내용은 공개 aws-neuron/torch-neuronx-model-support 데이터셋에서 가져오며, neuronx-cc 및 라이브러리 버전의 각 조합마다 하나의 Parquet 파일이 있습니다.

각 행에는 모델의 결과, 실패 시 오류, 전체 스택의 버전, 그리고 실행된 run.py가 포함됩니다. 다음과 같이 직접 쿼리할 수 있습니다.

import pandas as pd

df = pd.read_parquet("hf://datasets/aws-neuron/torch-neuronx-model-support/data")
df[df.model_id == "Qwen/Qwen3-0.6B"][["neuronx_cc", "library", "library_version", "neuron_cores", "result"]]

dataset card에서 각 결과의 정확한 의미를 확인할 수 있습니다.
