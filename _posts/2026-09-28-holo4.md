# Holo4: 범용 컴퓨터 사용 에이전트를 구동하다

[![Floor of screens from Holo4 benchmark runs across web apps, desktop software and mobile.](https://assets.hcompanyprod.fr/holo4/hf/holo4-cover.jpg)](https://assets.hcompanyprod.fr/holo4/hf/holo4-cover.jpg)

Holo4는 새로운 에이전트 모델 시리즈입니다. 27B dense와 35B-A3B Mixture of Experts의 두 가지 크기로 제공됩니다. 두 모델 모두 H Models API에서 사용할 수 있습니다. 또한 Holotron 3의 업데이트 버전인 Holotron4 Nano도 출시합니다.

Holo4는 이전 모델을 기반으로 하며, GUI, 코드, MCP 및 API 등 사용 가능한 모든 인터페이스를 통해 소프트웨어와 상호작용합니다. 학술 벤치마크에서 좋은 점수를 내지만, 실제 비즈니스 워크플로를 위해 구축했습니다. Agentic Task Factory가 생성한 작업을 포함해 대규모 환경 및 작업 집합에서 지도 학습과 강화 학습을 통해 훈련했습니다.

지금 시작하세요:

- 🤖 모델: [Holo4-27B](https://huggingface.co/Hcompany/Holo4-27B) | [Holo4-35B-A3B](https://huggingface.co/Hcompany/Holo4-35B-A3B) | [Holotron4 Nano](https://huggingface.co/Hcompany/Holotron4-30B-A3B)

- 🗂️ 전체 컬렉션(FP16, FP8, GGUF): [Holo4](https://huggingface.co/collections/Hcompany/holo4)

## 모든 인터페이스를 위해 구축된 모델 {#section-1}

Holo4는 화면을 클릭하고 입력하며, 자체 코드를 작성하고 실행하고, MCP 또는 API 도구를 호출합니다. 작업에 적합한 방식을 선택합니다. 대부분의 에이전트 모델은 하나의 인터페이스만을 대상으로 훈련됩니다. GUI 중심 모델은 화면 없이는 아무것도 볼 수 없고, 도구 호출을 선호하는 모델은 API가 없는 애플리케이션 앞에서는 멈춰 버립니다. 실제 업무는 그렇게 사일로화되어 있지 않으며, 하나의 비즈니스 작업에서도 이러한 서로 다른 접근 방식을 결합해야 할 수 있습니다.

Holo4는 데스크톱, 웹, Android, 코드 sandbox 및 비즈니스 API에서 실행됩니다. 각각의 경우에 동일한 모델을 사용하며 호출 방식도 같습니다. 플랫폼마다 다른 모델을 선택할 필요가 없습니다.

[![Holo4 benchmark results with cost per task, against Qwen3.8 27B and frontier models](https://assets.hcompanyprod.fr/holo4/hf/holo4-benchmark-table.png)](https://assets.hcompanyprod.fr/holo4/hf/holo4-benchmark-table.png)

Holo4 모델은 Qwen 기반 모델보다 크게 개선되었습니다. 장기 워크플로에서는 가장 강력한 폐쇄형 모델만이 Holo4보다 앞섭니다. OSWorld 2.0에서 Holo4 27B는 Opus 5.5의 81.8%에 비해 61.7%를 기록했고, Holo4 35B-A3B는 30.9%에 도달했습니다. 그러나 훨씬 적은 파라미터와 훨씬 낮은 비용으로 이를 달성합니다. 공개 벤치마크 점수의 근거가 되는 모든 궤적을 오픈 소스로 공개합니다. [trajectories.hcompany.ai](https://trajectories.hcompany.ai)에서 각 단계를 재생하거나 [Hugging Face](https://huggingface.co/datasets/Hcompany/trajectories)에서 다운로드할 수 있습니다.

## 프런티어 모델과 경쟁하면서도 비용은 일부에 불과 {#section-2}

데스크톱 제어(OSWorld 2.0)와 API 사용(AutomationBench)을 위한 가장 어려운 학술 벤치마크에서 Holo4는 작업당 훨씬 낮은 비용으로 프런티어 모델과 경쟁합니다.

[![OSWorld 2.0: average partial score vs. cost per task](https://assets.hcompanyprod.fr/holo4/hf/holo4-cost-osworld2.png)](https://assets.hcompanyprod.fr/holo4/hf/holo4-cost-osworld2.png)

[![AutomationBench: score vs. cost per task](https://assets.hcompanyprod.fr/holo4/hf/holo4-cost-automationbench.png)](https://assets.hcompanyprod.fr/holo4/hf/holo4-cost-automationbench.png)

OSWorld 2.0. 비용은 각 에이전트 실행의 입력 및 출력 토큰을 기준으로 추정했습니다. Holo4는 H Models API 요금(단일 실행)을 적용했습니다. Qwen3.8 27B: 모델 카드 점수이며, Alibaba Cloud 공개 가격에 따라 당사 실행의 토큰으로 비용을 계산했습니다. Qwen3.6 35B-A3B: 당사 harness에서 Alibaba Cloud 공개 가격을 적용해 단일 실행으로 측정했으며, 캐시 적중에는 입력 가격의 20%를 적용했습니다. OpenAI의 출시 데이터는 GPT 및 Opus의 effort sweep을 제공하며, 그 외 폐쇄형 및 오픈 웨이트 지점에는 [official OSWorld 2.0 leaderboard](https://osworld-v2.xlang.ai/)을 사용했습니다. 릴리스, harness 및 작업 하위 집합은 서로 다릅니다. 선은 폐쇄형 모델 중 지배되지 않는 점수-비용 쌍을 연결한 것이며, Holo4는 제외했습니다.

AutomationBench. Holo4, Qwen3.8 27B 및 Qwen3.6 35B-A3B: AutomationBench v1.0.6에서 당사 내부 harness로 점수와 비용을 측정했습니다. 그 외 모델: [AutomationBench README](https://github.com/zapier/AutomationBench)의 공개 세트 점수와 [official leaderboard](https://zapier.com/benchmarks)의 작업당 비용을 사용했으며, 후자는 비공개 세트에서 실행됩니다. Holo4는 평가가 완료되면 비공개 세트 점수를 보고할 예정입니다.

## 일을 해내는 AI {#section-3}

Agentic Task Factory의 환경과 작업으로 훈련된 Holo4 모델은 전문 소프트웨어에서 뛰어난 성능을 보입니다. 아래 예시는 Holo4 27B와 그 기반 모델인 Qwen3.8 27B를 나란히 보여 줍니다. 두 모델에 동일한 프롬프트와 harness를 사용했습니다.

### 3D 모델링 · 에펠탑

FreeCAD에서 에펠탑의 3D 모델을 만드세요. 축척은 1mm 대 1m로 하고, 원점을 중심으로 X축과 Y축에 맞춰 정렬하세요. 다음 설계에 따라 작업하세요.

탑은 모든 높이에서 평면상 정사각형이며, 절대 원형이 아닙니다. 중심축에서 모서리까지 측정한 반폭은 지면에서 62.5mm, 높이 57에서 32.5mm, 높이 115에서 17.5mm, 높이 276에서 9.35mm입니다. 이 높이들 사이에서 반폭은 지면 근처에서는 가파르게 줄어들고 위쪽으로 갈수록 완만해지는 매끄러운 곡선을 따르며, 절대 직선이 아닙니다.

사분면마다 하나씩, 총 네 개의 동일한 다리가 있으며 각 다리는 외측 모서리가 해당 프로파일을 따르는 정사각형 기둥입니다. 각 다리의 폭은 지면에서 14mm이고 높이 276에서 4mm까지 가늘어집니다. 다리는 지면에서 첫 번째 플랫폼까지 서로 떨어져 서 있고, 올라갈수록 서로 모입니다. 다리 사이의 공간을 채우는 것은 없습니다. 탑은 비어 있으며 어느 방향에서든 곧바로 통과해 볼 수 있어야 합니다.

세 개의 플랫폼은 각각 축을 중심으로 한 속이 찬 정사각형 슬래브입니다. 높이 57에서는 폭 72mm, 두께 4mm이고, 높이 115에서는 폭 40mm, 두께 3mm이며, 높이 276에서는 폭 22mm, 두께 3mm입니다.

높이 276에서 324까지 이어지는 정사각형 마스트로, 밑부분의 폭은 8mm이고 끝부분의 폭은 2mm가 되도록 가늘어집니다.

모든 부품은 0이 아닌 부피를 가진 닫힌 솔리드여야 하며, 어떤 부품도 다리 사이의 공간을 채워서는 안 됩니다.

Holo4 27B (84회 호출, 1.3M 토큰)

Qwen3.8 27B (60회 호출, 1.0M 토큰)

### 3D 모델링 · H 로고

FreeCAD에서 H 회사 로고의 3D 모델을 만드세요. 속이 찬 원판과 블록 형태의 산세리프 대문자 H를 나란히 배치하고, 두 도형을 같은 두께로 돌출하세요. 두 도형의 높이는 비슷하게 하고 서로 겹치지 않도록 떨어뜨려 배치하며, 원판의 중심은 H의 중간 높이와 맞추세요. 두 도형 모두 검은색으로 칠하세요.

Holo4 27B (94회 호출, 1.5M 토큰)

Qwen3.8 27B (118회 호출, 1.9M 토큰)

### 게임 디자인 · Pac-Man

Godot에서 Pac-Man 스타일의 게임을 만들고 실행 상태로 두세요.

격자에 배치된 벽으로 이루어진 직사각형 미로와 모든 열린 통로를 채운 펠릿이 있습니다. 플레이어 마커는 통로를 따라 계속 움직이며, 지나가는 각 펠릿을 먹고 점수를 1점씩 얻습니다. 유령 세 마리가 같은 통로를 이동하며 플레이어를 추적합니다. 유령이 플레이어를 잡으면 플레이어는 목숨을 하나 잃고 모든 요소가 시작 위치로 초기화됩니다. 점수와 목숨은 화면에 표시됩니다.

이 게임을 플레이할 사람은 없습니다. 플레이어는 간단한 휴리스틱으로 스스로 움직입니다. 각 교차로에서 가장 가까운 펠릿을 향해 이동하되, 유령이 가까이 있으면 유령에게서 멀어집니다. 게임은 키보드 입력 없이 무인으로 무기한 실행되어야 합니다.

정상적으로 작동하면 게임을 시작하고 계속 실행 상태로 두세요.

Holo4 27B (68회 호출, 2.4M 토큰, 268줄)

Qwen3.8 27B (197회 호출, 11.4M 토큰, 327줄)

## Holo4를 구축한 방법 {#section-4}

### 에이전트 작업 팩토리

당사의 내부 에이전트 파이프라인 집합은 실제 웹사이트 또는 오픈 소스 소프트웨어의 스크린샷과 같은 문서만으로 상호작용 환경과 검증 가능한 작업을 구축합니다. 지금까지 웹 앱, MCP 서버 및 데스크톱 환경 전반에서 약 10,000개의 작업을 생성했으며, GUI와 MCP를 통해 동일한 상태를 노출하는 하이브리드 환경도 포함됩니다.

[![Agentic Task Factory: sources, build, gates, runtime and output](https://assets.hcompanyprod.fr/holo4/hf/holo4-task-factory.png)](https://assets.hcompanyprod.fr/holo4/hf/holo4-task-factory.png)

### 훈련

[![Holo4 training: supervised fine-tuning on 127B tokens, two RL experts, one merged model](https://assets.hcompanyprod.fr/holo4/hf/holo4-training.png)](https://assets.hcompanyprod.fr/holo4/hf/holo4-training.png)

### Harness

훈련과 함께 OSWorld 2.0에서 에이전트 성능으로부터 얻은 피드백을 활용해 harness도 다시 구축했습니다. harness는 모델의 행동을 실행하고 수백 단계에 걸쳐 컨텍스트를 관리하는 루프입니다. 에이전트는 각 작업이 실패한 이유에 태그를 달았고, 엔지니어들은 수정 사항을 검토했습니다. 가장 큰 변경 사항은 수백 단계를 추적할 수 있는 신뢰할 만한 메모리와 데스크톱 머신 자체에서 사용할 수 있는 shell을 에이전트에 제공한 것입니다.

[![Automatic harness engineering: OSWorld 2.0 score of every evaluation run over time](https://assets.hcompanyprod.fr/holo4/hf/holo4-harness-history.png)](https://assets.hcompanyprod.fr/holo4/hf/holo4-harness-history.png)

Opus 5(70.2%)와 GPT-5.6 Sol(66.2%)은 비용-성능 그래프와 마찬가지로 [OpenAI's launch chart](https://openai.com/index/introducing-gpt-6-sol-and-luna/)의 v2026.08.08 오프라인 세트에서 최대 노력 부분 보상을 사용합니다. 그 외 참고 점수는 모델 카드와 공식 리더보드에서 가져왔습니다. 작업 릴리스, 하위 집합 및 harness는 서로 다릅니다.

## Holotron4 Nano {#section-5}

당사의 post-training 스택은 새로운 파운데이션 모델에 맞게 조정되고, 인터페이스와 환경 전반에서 일반화되는 에이전트를 생성하도록 설계되었습니다. [NVIDIA Nemotron Coalition](https://hcompany.ai/newsroom/h-joins-nemotron-coalition)의 구성원으로서, Holotron 3의 후속 작업으로 최신 스택을 Nemotron 3 Nano Omni 모델에 적용했습니다.

동일한 레시피를 통해 Nemotron 3 Nano Omni는 Holotron4 Nano로 변환됩니다. Holotron4 Nano는 GUI 워크플로와 MCP, API 또는 코딩 sandbox를 노출하는 환경에서 기반 모델보다 크게 개선된 범용 에이전트 모델입니다.

[![Holotron4 Nano vs. Nemotron 3 Nano Omni across five benchmarks](https://assets.hcompanyprod.fr/holo4/hf/holotron4-benchmarks.png)](https://assets.hcompanyprod.fr/holo4/hf/holotron4-benchmarks.png)

개선 폭은 Nemotron 3 Nano Omni 대비 절대 퍼센트포인트 향상입니다.

이러한 향상은 당사의 레시피가 잘 전이되며 범용 모델을 에이전트 전문가로 전환할 수 있음을 보여 줍니다. 이 레시피는 특정 모델 크기에 종속되지 않습니다.

## 직접 실행해 보기 {#section-6}

두 크기 모두 현재 [H Models API](https://hub.hcompany.ai/models-api/introduction)에서 사용할 수 있습니다. 가중치는 [Hugging Face](https://huggingface.co/collections/Hcompany/holo4)에서 BF16, FP8, NVFP4 및 4-bit GGUF 형식으로 제공되며, 소형 모델인 [Holotron4 Nano](https://huggingface.co/Hcompany/Holotron4-30B-A3B)도 함께 제공됩니다.

추론을 더욱 가속하기 위해 최적화된 DSpark drafter 체크포인트를 며칠 내로 출시할 예정입니다.
